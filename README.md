# MyGacha

---

## ✨ ฟีเจอร์หลักในระบบ

### 1. ระบบจำลองการฉีกซองการ์ดเสมือนจริง (Interactive Pack Opening)
- **ลากนิ้วหรือเมาส์ปาดตามเส้นประแนวนอน (Swipe to Tear):** ลากกรรไกร/รอยฉีกตามเส้นประ เมื่อฉีกครบ 85%+ ซองจะเปิดออก
- **เสียงฉีกซองฟอยล์สมจริง (Synthesized Foil Tear Sound):** สร้างเสียงผ่าน Web Audio API ไม่ต้องโหลดไฟล์ภายนอก รันได้ 100% ไม่มีเสียงหลุด
- **การ์ดสไลด์ขึ้นและเปิดทันที (Immediate Face-up Reveal):** การ์ดจะสไลด์พุ่งขึ้นมาจากซองและเปิดหงายหน้าให้เห็นทันที
- **การันตีอัตราการออก (Drop Rate Engine):** คัดสรรการ์ดตามสัดส่วน % โอกาสออกของแต่ละระดับอย่างเป็นกลาง
- **แสดงจำนวนที่มีในไอดี:** มีป้ายบอก `มีจำนวน [X] ใบ` ใต้การ์ดทุกใบ
- **คลิกเพื่อตรวจดูรายละเอียด:** กดที่การ์ดเพื่อดูชื่อ, ความสามารถ และคุณสมบัติพิเศษ พร้อมปุ่มปิด `(X)`

### 2. สตูดิโอสร้างซองการ์ด (Creator Studio Wizard)
- **Step 1 (CreateCardsPack):** ตั้งชื่อการ์ด/แฟรนไชส์, ชื่อซีรีส์, แท็ก, จำนวนการ์ดต่อซอง (Preset 3, 4, 5⭐), ราคาต่อซอง (Preset 150, 300, 500⭐), อัปโหลดภาพหน้าปกซอง (Drop Zone) พร้อมพรีวิวและระบบยืนยันการลบ
- **Step 2 (CreateCards):** เลือกระดับความแรร์ (C, R, RR หรือเพิ่มระดับเอง), กำหนด % โอกาสออก, อัปโหลดภาพการ์ดแบบ Batch พร้อมระบบตรวจจับภาพซ้ำ `(⚠ มีการแนบภาพซ้ำ)`
- **Step 3 (CreateCardsData):** กรอกชื่อการ์ด ✏️, ความสามารถการ์ด ✏️ (ไม่บังคับกรอก) และกดปุ่ม `(+)` เพื่อเพิ่มช่องข้อมูลคุณสมบัติพิเศษได้อิสระ
- **แถบเมนูด้านบน:**
  - `Test`: ทดสอบเปิดซองการ์ดที่เพิ่งสร้างได้ทันที
  - `Save`: บันทึกเป็นดราฟต์
  - `Load`: โหลดชุดการ์ดเดิมกลับมาแก้ไข
  - `Publish`: เผยแพร่ชุดการ์ดขึ้นหน้าแผง

### 3. ระบบสมาชิก & เศรษฐกิจเกม (Daily Reward & Auth)
- **ปุ่มรับเหรียญรายวัน (Daily Reward):** สมาชิกสามารถกดรับฟรีวันละ **2,000 Coin** ทุกวัน
- **ระบบสมาชิก:** Sign In / Sign Up พร้อมลูกตาเปิด-ปิดดูรหัสผ่าน และ Popup *"Want to save password"*
- **หน้าแรก (พร้อมแล้ว):** แสดงรายการซองการ์ด พร้อมความคืบหน้าการสะสม `[มีอยู่] / [ทั้งหมด]`

### 4. แกลเลอรี่ส่วนตัว (Personal Card Album)
- แสดงการ์ดทั้งหมดที่ตนเองครอบครอง
- **การ์ดที่ยังไม่เคยเปิดได้จะแสดงเป็นสีเทา (Grayscale Locked)** พร้อมไอคอนแม่กุญแจ
- การ์ดที่เปิดได้แล้วจะแสดงภาพสีสันสดใส และจำนวนใบที่ครอบครอง

### 5. การเชื่อมต่อฐานข้อมูล Supabase
- ใช้งานได้ทั้งแบบออฟไลน์ (Local Storage อัตโนมัติ) และเชื่อมต่อ Supabase Database แบบออนไลน์
- มีไฟล์ `supabase_schema.sql` พร้อมให้คัดลอกไปรันใน Supabase SQL Editor ทันที

## 🚀 วิธีเปิดใช้งาน

1. เปิด Terminal ในโฟลเดอร์ `d:\make_website\MyGacha`
2. รันคำสั่ง:
   ```bash
   npm run dev
   ```
3. เปิดเบราว์เซอร์ไปที่: `http://localhost:5173`
